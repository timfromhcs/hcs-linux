# HCS Linux Trademark Guidelines

"HCS Linux", "HCS Brain", "HCS Shell", the HCS geometric hexagon/neural logo, and related marks are trademarks of the HCS Linux Project and its maintainers.

## Permitted Uses

You may:
- State truthfully that your software runs on, is compatible with, or was built using HCS Linux.
- Distribute unmodified official ISO images, binary packages, and source releases.
- Use the wordmark to refer to the project in news, reviews, blogs, and documentation.

## Restrictions

You may not:
- Use the HCS Linux name, logo, or visual marks in a manner that implies endorsement, sponsorship, or certification without explicit written permission.
- Distribute modified versions of HCS Linux while retaining official HCS Linux branding and logos, unless clearly designated as a fork/remix with distinct branding.
- Register domain names, trademarks, or company names containing "HCS Linux" or confusingly similar variations.
