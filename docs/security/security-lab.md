# Security Lab (Authorized Research Environment)

The HCS Security Lab provides authorized security practitioners with pre-packaged diagnostic, analysis, and network auditing utilities.

## Rules of Engagement

1. **Authorized Use Only:** Security Lab tools must be operated solely against systems, networks, and software where explicit written authorization has been granted.
2. **On-Demand Activation:** Security Lab utilities and daemons do not run resident in memory to protect system responsiveness and prevent unintended network interactions.

## Tooling Classes

- **Network Discovery & Traffic:** `nmap`, `tshark`, `tcpdump`
- **Binary Analysis & Forensics:** `radare2`, `binwalk`
- **Wireless Diagnostics:** `aircrack-ng`
- **Web Security Auditing:** `sqlmap`
